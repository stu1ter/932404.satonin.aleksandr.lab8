# Кулинарная книга — Веб-приложение для управления рецептами и ингредиентами

**Лабораторная работа №8. Итоговый мини-проект**  
**Вариант 9.** Тема: «Рецепты и ингредиенты»

Полноценное клиент-серверное веб-приложение для создания, просмотра, редактирования и удаления кулинарных рецептов, управления списком ингредиентов, фильтрации блюд и подсчета суммарного времени приготовления.

---

## Технологический стек

* **Backend:** Node.js, Express v5.3.0
* **База данных:** SQLite3 v6.0.1
* **Frontend:** HTML5, CSS3, JavaScript 

---

## Функциональные возможности

* **CRUD-операции для рецептов:** добавление, просмотр, редактирование и удаление записей из базы данных.
* **Управление ингредиентами:** привязка продуктов с указанием количества и единиц измерения к конкретному рецепту (реализовано через модальное окно).
* **Фильтрация:** выбор рецептов по уровню сложности (`Легко`, `Средно`, `Сложно`) и максимальному времени приготовления в сайдбаре.
* **Агрегация данных:** автоматический подсчет количества найденных рецептов и их суммарного времени приготовления.
* **Инициализация БД:** при первом запуске база данных создаётся автоматически и заполняется тестовыми записями.

---

## Структура базы данных (ER-диаграмма)

База данных `recipes.db` состоит из двух связанных таблиц с поддержкой каскадного удаления (`ON DELETE CASCADE`):

```text
+-----------------------------------+         +-----------------------------------+

|              recipes              |         |            ingredients            |
+-----------------------------------+         +-----------------------------------+

| PK | id           | INTEGER       |<---+    | PK | id           | INTEGER       |
|    | name         | TEXT          |    +----| FK | recipe_id    | INTEGER       |
|    | difficulty   | TEXT          |         |    | name         | TEXT          |
|    | cooking_time | INTEGER       |         |    | quantity     | REAL          |
+-----------------------------------+         |    | unit         | TEXT          |
                                              +-----------------------------------+
```

* **`recipes`** — хранит основную информацию о блюде (название, сложность, время в минутах).
* **`ingredients`** — хранит состав каждого рецепта (внешний ключ `recipe_id`, название продукта, количество и единица измерения).

## Примеры API-запросов

Сервер предоставляет REST API по базовому пути `/api/recipes`:

### 1. Получить список всех рецептов (с фильтрацией)
* **Метод:** `GET /api/recipes`
* **Параметры запроса (опционально):** `difficulty`, `maxTime`
* **Пример запроса:**
  ```http
  GET http://localhost:3000/api/recipes?difficulty=Легко&maxTime=30
  ```
* **Пример ответа (`200 OK`):**
  ```json
  [
    {
      "id": 1,
      "name": "Блины",
      "difficulty": "Легко",
      "cooking_time": 20,
      "ingredients": [
        { "id": 1, "recipe_id": 1, "name": "Мука", "quantity": 200, "unit": "г" },
        { "id": 2, "recipe_id": 1, "name": "Молоко", "quantity": 0.5, "unit": "л" }
      ]
    }
  ]
  ```

### 2. Получить статистику (агрегация времени)
* **Метод:** `GET /api/recipes/stats`
* **Пример запроса:**
  ```http
  GET http://localhost:3000/api/recipes/stats?difficulty=Сложно
  ```
* **Пример ответа (`200 OK`):**
  ```json
  {
    "totalTime": 90,
    "count": 1
  }
  ```

### 3. Создать новый рецепт
* **Метод:** `POST /api/recipes`
* **Тело запроса (`application/json`):**
  ```json
  {
    "name": "Омлет",
    "difficulty": "Легко",
    "cooking_time": 10
  }
  ```
* **Пример ответа (`201 Created`):**
  ```json
  {
    "id": 3,
    "name": "Омлет",
    "difficulty": "Легко",
    "cooking_time": 10,
    "ingredients": []
  }
  ```

### 4. Обновить рецепт
* **Метод:** `PUT /api/recipes/:id`
* **Тело запроса (`application/json`):**
  ```json
  {
    "name": "Омлет с сыром",
    "difficulty": "Легко",
    "cooking_time": 15
  }
  ```
* **Пример ответа (`200 OK`):**
  ```json
  {
    "updated": 1
  }
  ```

### 5. Добавить ингредиент к рецепту
* **Метод:** `POST /api/recipes/:id/ingredients`
* **Тело запроса (`application/json`):**
  ```json
  {
    "name": "Яйцо куриное",
    "quantity": 3,
    "unit": "шт"
  }
  ```
* **Пример ответа (`201 Created`):**
  ```json
  {
    "id": 5,
    "recipe_id": 3,
    "name": "Яйцо куриное",
    "quantity": 3,
    "unit": "шт"
  }
  ```

### 6. Удалить рецепт
* **Метод:** `DELETE /api/recipes/:id`
* **Пример ответа (`200 OK`):**
  ```json
  {
    "deleted": 1
  }
  ```
